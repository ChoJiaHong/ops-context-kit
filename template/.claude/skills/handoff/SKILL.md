# /handoff：結束或交出一項工作

1. **找到任務**：`python3 tools/task.py current --session <id>`（session id 在 `[session] id:` 那一行）。沒有綁定就問使用者是哪個任務。
2. **驗證 done-when**：用觀察系統的指令證明，附關鍵輸出；要撐過原本出錯的時間點或條件（K5）。沒有證據就寫「未驗證」，不要寫完成。
3. **收尾檢查**（K8）：唯讀檢查同類目標（其他主機、prod 的對應資源）有沒有同樣問題，只報不改。
4. **寫回任務紀錄**：
   - `## Result`：做了什麼、證據、留下的變更與回滾方式、和紀錄不符的地方。
   - `status`：`done`（驗證過）、`waiting`（等人或等時間窗口）、`blocked`（卡住）。
   - `next`：下一步，一句話。
   - 長期有用的事實寫回 TRUTH.md。
5. **接手卡**：這次有 prod 變更或不可逆操作時，在 Result 裡加一段「接手卡」，寫給凌晨被叫醒、沒看過這個 session 的人：
   - 改了什麼、為什麼。
   - 怎麼看出它壞了（指令）。
   - 怎麼回滾（指令）。
6. **教訓**：這次學到、以後每個 session 都該知道的事，附加一行到 `lessons/inbox.md`（日期、任務 ID、一句話、證據）。不要直接改 AGENTS.md 或 CLAUDE.md，由使用者審過再合併。
7. **回覆**：結果與證據、接手卡（有的話）、還沒解決的事，以及你的建議：結束這個 session、繼續，或為後續工作開新任務（`/start`）。
