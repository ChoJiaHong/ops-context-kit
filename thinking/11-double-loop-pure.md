# 11 純粹的雙向迴圈

2026-11-07 與作者確認。這是目前最抽象、作者接受的形式。

## 定義

**雙向迴圈：兩個方向相反、互相餵養的迴圈。**

- **向下迴圈（具體化）**：從抽象出發，一層層加上具體條件，直到它能實際操作、能被檢驗。
- **向上迴圈（抽象化）**：從具體結果出發，一層層拿掉條件，直到再拿掉一個就不成立。
- **交接**：向下的終點是向上的起點；向上的終點又是下一次向下的起點。
- **每轉一圈**：抽象的那一端更精簡，具體的那一端更可靠。

| | 內容 |
|---|---|
| 兩端 | 抽象 ↔ 具體 |
| 向下的停止點 | 能實際操作、能被檢驗 |
| 向上的停止點 | 再拿掉一個條件就不成立 |

## 不包含的東西

不規定處理什麼對象，也不帶判準。判準是套用到某個領域時才加進來的。例如 [09](09-double-loop.md) 用在「有範圍的主張」上，加了三個判準：勝過基準、硬湊檢驗（拿掉差異，優勢要消失）、能說「不」的證據。
