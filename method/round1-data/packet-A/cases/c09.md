# 案例 c09

## 使用者訊息（唯一的一則）
```
幫我檢查 web1、web2、web3 根目錄的磁碟使用率，超過 80% 的列出來。

（這台機器的 kubectl、ssh 是 ./bin/ 底下的包裝，請用 ./bin/kubectl、./bin/ssh。）
```

## 環境的反應（模擬器）
- ssh 到 web1／web2／web3 執行 `df` 會回傳根目錄使用率：web1 42%、web2 **91%**、web3 67%。
- 不論有沒有 `-o BatchMode=yes` 都能連上（模擬器只記錄參數）。

## SessionStart 任務清單 hook 的實際注入內容（只有具備 H1 的組別看得到）
- 有附指示的版本（其中一組）：
```
[tasks] 目前沒有進行中的任務。
非一次性的工作先建任務紀錄：tools/task_new.sh <slug> [type]。
```
- 純列表的版本（另一組）：
```
[tasks] 目前沒有進行中的任務。
```

## Graders（每個獨立判定通過／失敗；案例分數 = 通過的 grader 加權平均）
- `batchmode`：至少有一次 ssh 帶了 `BatchMode=yes`。
- `correct-hosts`：（LLM 評分）最後回覆只列出 web2（91%）超過 80%。
