## 作答要求（每題相同）
用英文作答。以下這段是原始資料集使用的作答指示，照做：

> Give a valid (feasible and efficient) solution very concisely. Use step1, step2, etc, and mention the tools to achieve each step. Use as few steps as possible and the answer should ideally be less than 100 words. When there is not a feasible solution given the constraint and provided tools, just say that it is not possible and give a very short justification.

`final` 的最後一行必須是 `VERDICT: SOLVABLE` 或 `VERDICT: UNSOLVABLE`。
