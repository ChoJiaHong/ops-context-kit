## 核心骨架
基準解：同類問題已被公認、可用的標準做法，作為比較起點。
情境差異：此具體情境相對一般情況多出的特殊資源、基礎設施或約束。
瓶頸：基準解在此情境下仍可用，但代價最高或表現最差的地方。
配對：判斷某個差異能否消除、降低瓶頸，或讓另一方案取得相對優勢。
調整解：依配對結果改寫基準解，使差異真正參與解題。
檢驗：拿掉該差異後方案是否仍成立（仍成立即硬湊），並確認目標與原問題一致、效用確實高於基準解。

## 形式化
D = Δ(具體情境, 一般類別)；若 Match(L(S₀), D) 成立，則 S₁ = Adapt(S₀, L, D)
有效條件：Goal(S₁) = Goal(P₀)，且 U(P, S₁) − U(P, S₀) > 0
可選延伸：逐步移除特定情境，直到優勢 ≤ 0，所得範圍即 P*。

## 最符合的問題 P*
P*：目標固定、同類問題已有成熟通用解，而特定情境因擁有特殊資源或約束，能把通用解調整成相對更優方案的問題。
進入條件：(1) 能指出通用解與其瓶頸；(2) 情境中存在非表面的特殊資源；(3) 目標不會在過程中被改寫；(4) 新舊方案能以時間、成本或成功率粗略比較。四項愈能成立，愈有優勢。

## 不適用的情況
1. 全新問題，沒有可比較的成熟基準解。
2. 情境沒有真正的特殊條件，差異只是貼標籤，檢驗時會被判為硬湊。
3. 目標模糊或有爭議，需要先釐清目標，而不是調整解法。
4. 瓶頸來自執行力或資源總量不足，或問題可直接用明確指標做窮舉、最佳化。

## 為 P* 調整後的模型
1. 固定原始目標，並把它抽象成一般問題類別。
2. 列出該類別的基準解，挑出最強者。
3. 找出基準解在此情境下的瓶頸。
4. 列出情境相對一般情況的差異，包含可重新詮釋的既有資源。
5. 配對差異與瓶頸，產生調整解。
6. 做硬湊與目標一致檢驗，並比較效用；不過關就換差異重做，過關後可選擇性向上泛化。
